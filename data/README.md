# Data

The data directory contains data files used by the code generator. The data files are generated from STM32CubeMX and are licensed under ST SLA0048. They are used for STM32 MPU pin validation and device tree (DTS) generation. The RIFSC header files are generated from the RIFSC database and are originally licensed under BSD-3-Clause; the YAML and Rust file derived from the RIFSC database are licensed under Apache-2.0.

All parser, checker and code generator are licensed under Apache-2.0.
