# consortium

A Rust-based abstraction for HMP like STM32MP2 and i.MX 95, providing async inter-processor communication primitives.

> [NOTE]
>
> This project is in early stages of development, and is not yet ready for production use. Contributions are welcome, but please be aware that the API may change significantly as the project evolves.
>
> Currently the project is pausing because of the author's academic commitments, but it will be resumed in mid-June 2026.
