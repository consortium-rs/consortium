# What HAMPU is

The Heterogeneous and Asymmetric Multiprocessing Units (HAMPU) is a term used to describe a computing system that consists of multiple processing units with multiple purposes and capabilities. Specifically, a HAMPU system mostly include at least one application core and at least one real-time core (most frequently Cortex-A and Cortex-M cores, respectively). The application core is designed for general-purpose computing tasks, while the real-time core is optimized for handling time-sensitive tasks and real-time applications. In addition, modern HAMPU systems may also include other types of processing units, e.g., NPU (Neural Processing Unit), GPU (Graphics Processing Unit), DSP (Digital Signal Processor), etc., to further enhance the system's performance and capabilities. The combination of different types of processing units in a HAMPU system allows for efficient execution of a wide range of applications, from general-purpose computing to real-time processing and specialized tasks.

## Comparison with other architectures

Compared to multicontroller unit (MCU) that only owns Cortex-M or RISC-V core, HAMPU system can load and run advanced applications with standard OS (e.g., Linux) support, thus reducing the overhead of porting and maintaining applications and enabling a more comfortable deploy and run environment. For example, the application core can run a Linux-based OS to handle human-machine interaction logic via WPE WebKit, a quantized neural network at scale for image recognition via an NPU, and simultaneously, reading data from peripherals and controlling actuators (e.g., via CAN bus) on the real-time core without interrupting the application core.

Compared to application processors that only owns Cortex-A or even x86 core, HAMPU system can offload time-sensitive tasks to the real-time core, thus improving the overall system performance and responsiveness. Through bare-metal or RTOS programming, we don't need to patch the Linux runtime to achieve pseudo real-time performance; instead, the real-time core can guarantee the deterministic execution of time-sensitive tasks, ensuring that they are completed within the required time constraints.

Compared to the serial-wired upper-lower architecture, HAMPU system integrates the application core and real-time core on the same chip, thus reducing the communication latency and improving the overall system performance. The application core and real-time core can communicate with each other through shared memory or inter-core communication mechanisms, enabling efficient data exchange and coordination between the two cores. This integration allows for faster response times and improved performance compared to traditional architectures where the application processor and microcontroller are separate entities.

### NXP i.MX 95

The NXP i.MX 95 is a flagship HAMPU chip that features a powerful combination of Cortex-A55 application cores, Cortex-M7 real-time cores, Cortex-M33 system manager cores, and integrated NPUs, GPUs, and VPUs. This chip is designed for high-performance applications that require advanced processing capabilities, such as artificial intelligence, machine learning, and multimedia processing. The i.MX 95 provides a robust platform for developers to build innovative applications that leverage the strengths of both the application cores and real-time cores, while also benefiting from the integrated specialized processing units for enhanced performance and efficiency.

To develop with the i.MX 95, you can use the [FRDM-IMX95 board](https://www.nxp.com/design/design-center/development-boards-and-designs/FRDM-IMX95). We provide official examples and tutorials for this board in the Consortium Book, which will guide you through the process of setting up your development environment, writing code for both the application core and real-time core, and leveraging the integrated NPUs, GPUs, and VPUs to create powerful applications.

### STM32MP257

The STM32MP257 is another popular HAMPU chip that features a combination of Cortex-A35 application cores, Cortex-M33 real-time cores, and integrated NPUs and GPUs. This chip is designed for a wide range of applications, including industrial automation, consumer electronics, and IoT devices. It is more specialized for critical mission, because it passes SIL 3 certification; simultaneously, it can leverage both Cortex-A35 and Cortex-M33 cores to execute Trusted Firmware via TrustZone and achieve the resource partition isolation. The STM32MP257 provides a versatile platform for developers to create innovative applications that require a balance of performance, security, and real-time capabilities.

To develop with the STM32MP257, you can use the [STM32MP257F-DK board](https://www.st.com/en/evaluation-tools/stm32mp257f-dk.html). We also provide official examples and tutorials for this board in the Consortium Book, which will help you get started with developing applications that leverage the capabilities of both the application cores and real-time cores, as well as the integrated NPUs and GPUs for enhanced performance and efficiency.

## Typical chips

The most common types of HAMPU chips include Cortex-A and Cortex-M cores, which are widely used in various applications. For example, the STM32MP1 series from STMicroelectronics features a dual-core Cortex-A7 application processor and a Cortex-M4 real-time core, while the i.MX 8M series from NXP Semiconductors includes a quad-core Cortex-A53 application processor and a Cortex-M4 real-time core. Other examples of HAMPU chips include the Qualcomm Snapdragon series, which integrates multiple processing units such as CPUs, GPUs, NPUs, and DSPs to provide high performance and efficiency for mobile devices and other applications.

In Consortium, we more focus on the latest-generation HAMPU chips, e.g., the NXP i.MX 9x series and the STM32MP2x series. Compared to their predecessors, these chips feature more powerful application cores (e.g., Cortex-A55) and real-time cores (e.g., Cortex-M33). Crucially, their `Cortex-M33` cores allows the _resource partition isolation_, which alleviates the security concerns of HAMPU systems that different cores may race for the same resource (e.g., memory, peripherals, etc.) and cause security vulnerabilities. (In this case, some of designs before this generation may have an NXP i.MX 8M Plus chip plus an STM32F4 chip.)

## Benefits and challenges

One cost of the HAMPU is its increased complexity in software development and system design. Developers need to consider the interactions and coordination between the different processing units, which can be more challenging than developing for a single-core system. Additionally, the integration of multiple processing units on a single chip can lead to increased power consumption and heat generation, which may require additional cooling solutions and power management strategies. Despite these challenges, the benefits of HAMPU systems in terms of performance, flexibility, and capabilities make them an attractive choice for a wide range of applications, from consumer electronics to industrial automation and beyond.

The Consortium framework is designed to address the challenges of developing software for HAMPU systems by providing a unified programming model and tools that allow developers to easily leverage the capabilities of both the application core and real-time core. By abstracting away the complexities of coordinating between different processing units, the Consortium framework enables developers to focus on building their applications without worrying about the underlying hardware details. With the Consortium framework, developers can write code that runs seamlessly across both the application core and real-time core, allowing them to take full advantage of the capabilities of their HAMPU systems while minimizing the development overhead and complexity.
